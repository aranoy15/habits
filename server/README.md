# Habits Server

Сервер для приложения по отслеживанию привычек.

## Структура проекта

```
.
├── cmd
│   └── api           # Точка входа приложения
├── internal
│   ├── handlers      # HTTP обработчики
│   ├── models        # Модели данных
│   ├── repository    # Слой доступа к данным
│   └── service       # Бизнес-логика
└── .env              # Конфигурация окружения
```

## Запуск проекта

1. Убедитесь, что у вас установлен Go 1.21 или выше
2. Склонируйте репозиторий
3. Создайте файл `.env` на основе `.env.example`
4. Запустите сервер:

```bash
go run cmd/api/main.go
```

## API Endpoints

- `GET /health` - проверка работоспособности сервера
- `GET /api/habits` - получение списка привычек
- `POST /api/habits` - создание новой привычки

## Технологии

- [Gin](https://github.com/gin-gonic/gin) - веб-фреймворк
- [godotenv](https://github.com/joho/godotenv) - загрузка переменных окружения
